
# GamingOS

A browser-based desktop environment designed to give console users a PC-like experience.

## GamingOS Liquid Edition

Inspired by:
- macOS Liquid Glass
- Windows 11
- Kali Linux
- GRUB boot interfaces

## Features

- Liquid Glass desktop
- Floating application dock
- Start menu
- Draggable application windows
- Minimize and maximize
- Browser viewer
- Game library
- Calculator
- Terminal simulator
- Notes with local saving
- Custom wallpapers
- Custom accent colors
- Fullscreen support
- Keyboard and mouse support
- Responsive interface

## Applications

| Application | Description |
|---|---|
| Browser | Embedded web viewer |
| Games | Browser game launcher |
| Files | File manager interface |
| Settings | Desktop customization |
| Calculator | Working calculator |
| Terminal | Simulated terminal |
| Notes | Persistent local notes |

## Installation

No installation required.

Open the website in a modern browser.

## GitHub Pages

1. Open repository Settings.
2. Navigate to Pages.
3. Select Deploy from a branch.
4. Select main.
5. Select /(root).
6. Save.

## Browser compatibility

The built-in browser uses an iframe.

Some websites prevent embedding through security headers.

A remote Chromium browser service is required for broader website compatibility.

## Storage

Settings and notes use browser localStorage.

Clearing browser data can remove locally stored information.
